飲食店のテイクアウト・モバイルオーダー注文サイト制作TAKEOUT

カフェ、パン屋、お弁当、居酒屋のオードブル、キッチンカー。スマホから注文できる、お店専用の注文ページを作ります。電話注文の手間を減らして、常連のお客様の注文を自分のお店で受けられるように。

WHAT YOU GET // できること

お店の名前で、
自分の注文ページを。

01

スマホで注文

ORDER

お客様がスマホでメニューを見て、そのまま注文。写真つきのメニューで、迷わず選べる画面にします。

02

受け取り時間の指定

PICK UP

受け取りの時間を選んでもらい、混雑する時間を分散。電話で注文を受ける手間を減らします。

03

注文の通知

NOTIFY

注文が入ったらお店にすぐ通知。お店の運営に合わせて、必要な機能だけを組み込みます。

WHY // 自分のページを持つ理由

大手のデリバリー・注文サービスは便利な反面、売上ごとの手数料や月額がかかります。お店専用の注文ページがあれば、常連のお客様からの注文を自分のお店で受けられます。ドメイン（URL）もお店の名前で持てます。

カフェ・パン屋・お弁当朝やお昼のテイクアウト予約に。
居酒屋・バーオードブルやパーティーメニューの予約に。
キッチンカー・イベント出店並ばずに受け取れるモバイルオーダーに。
PROCESS // 導入の流れ

相談から公開まで。

  1. ご相談メニュー数や、今の注文の受け方をお聞きします。
  2. ご提案・お見積り必要な機能と費用をご提案します。
  3. メニュー登録・制作写真とメニューを入れて、画面を確認しながら作ります。
  4. テスト・公開実際に注文してみて、問題なければ公開します。
  5. 運用サポートメニュー変更や機能追加もご相談ください。
FAQ // よくある質問

よくある質問

Q.01どんなお店で使えますか？

カフェ、パン屋、お弁当屋、居酒屋のオードブル予約、キッチンカーなど、持ち帰りや事前注文があるお店に向いています。

Q.02注文が入ったらどうやって分かりますか？

注文が入るとお店に通知が届くようにします。通知の受け取り方は、お店の運営に合わせてご相談ください。

Q.03支払いはどうなりますか？

店頭でのお支払いから始めることもできますし、オンライン決済を組み込むこともできます。お店に合った方法をご提案します。

Q.04メニューや値段は自分で変えられますか？

変更の頻度に合わせて、ご自身で更新できる形か、こちらで更新する形かをご提案します。

Q.05横須賀以外のお店でも頼めますか？

はい。横須賀・三浦・逗子・葉山・横浜を中心に、全国からオンラインでご依頼いただけます。

Q.06費用はどのくらいですか？

メニューの数や必要な機能によって変わるため、ご相談のうえでお見積りします。見積もりは無料です。

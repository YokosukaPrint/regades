REGADES（レガデス）は、横須賀を拠点にした小さなスタジオです。アイデアを形にするところから、ウェアに刷るところ、売る場所をつくるところまで。4つの事業で、ひとつの「つくる」をまるごと引き受けます。

01 — PLAN

REGADES

企画・デザイン

チームやお店、ブランドの「こんなものを作りたい」を、形にするところから始めます。ロゴやグラフィックのデザイン、オリジナルアパレルの企画、販促物の制作まで。

デザインからプリント、販売サイトまで社内でつながっているので、途中で別の会社に頼み直す必要がありません。

REGADES SHOP →

ロゴ・グラフィック

チームロゴ、お店のロゴ、看板やウェア用のグラフィックをデザインします。手書きのラフや写真からでも大丈夫です。

オリジナルアパレル

ブランドやイベントのアパレルを、ボディ選びからデザイン、生産まで一緒に企画します。

印刷用データ作成

手持ちの画像やロゴを、シルクスクリーンやDTFで刷れるデータに整えます。

02 — PRINT

YOKOSUKA
PRINT

ウェアのプリント

Tシャツ・パーカー・トートバッグなどのオリジナルプリントを、1枚から承ります。チームウェア、イベントTシャツ、お店のユニフォーム、クリエイターのブランド商品まで。

シルクスクリーンやDTFなど、デザインに合わせた方法でプリント。デザインの相談から仕上がりまで横須賀で対応し、全国へ発送します。

04 — WEB

WEB

サイト・システム制作

お店や会社のホームページから、テイクアウト・モバイルオーダーなどの注文システム、日々の業務を楽にする仕組みまで。月額の高いサービスに頼らず、必要なものを必要な分だけ作ります。

WEB制作について →

飲食店のテイクアウト注文サイト制作 ／ Wixからの乗り換え

ホームページ制作

お店・会社・チームのサイトを制作します。スマホで見やすく、検索やAIにも見つけてもらいやすい作りに。

オーダーシステム

飲食店のテイクアウト・モバイルオーダーなど、お客様が注文できる仕組みを作ります。

業務システム

PROCESS // 乗り換えの流れ

URLはそのまま、
中身だけ新しく。

  1. 今のサイトを確認ページ構成・文章・写真・ドメインの契約状況を確認します。
  2. 新しいサイトを制作内容を引き継いで、デザインを作り直します。
  3. 仮のURLで確認今のサイトは動かしたまま、新しいサイトを仮のURLで確認します。
  4. ドメインを切り替え問題がなければ、今のドメインのまま新しいサイトに切り替えます。
  5. 解約・検索の設定旧サービスの解約の注意点のご案内と、Googleへの登録まで対応します。

FAQ // よくある質問

よくある質問

Q.01Wixで買ったドメインのまま乗り換えられますか？

はい、できます。ドメインの設定を新しいサイトに向けるだけで、URLは変わりません。ドメインの契約は残したまま、サイトのプランだけを見直せます。

Q.02乗り換えの間、サイトが見られなくなりますか？

新しいサイトを仮のURLで確認してから切り替えるので、見られない時間はほとんどありません。切り替えの反映に数時間ほどかかることがあります。

Q.03Wixの解約はいつすればいいですか？

新しいサイトへの切り替えが終わって、写真などのデータを移し終わってからが安全です。ドメインの契約とサイトのプランは別なので、解約の範囲もご案内します。

Q.04ペライチやジンドゥー、STUDIOからも乗り換えできますか？

はい。サービスに関係なく、今のサイトの内容を引き継いで作り直せます。

Q.05更新は自分でできますか？

更新の頻度や内容に合わせて、ご自身で更新できる形か、こちらで更新する形かをご提案します。

Q.06費用はどのくらいですか？

ページ数や機能によって変わるため、今のサイトを拝見したうえでお見積りします。見積もりは無料です。
